# Admin App API Reference

All routes are Next.js App Router API routes under `/api/`. All responses are JSON unless noted otherwise.

## Authentication

Most endpoints use `createServiceClient()` from `@repo/db/service`, which creates a Supabase client with the service role key (full database access, bypasses RLS). No user-facing auth tokens are required for internal calls.

Exceptions:

- **`POST /api/hooks/notify`** -- authenticates via `X-Hook-Secret` header (shared secret).
- **`POST /api/slack/commands`** -- authenticates via Slack HMAC-SHA256 signature verification.
- **`POST /api/portfolio/verify`** -- public endpoint with IP-based rate limiting (CORS restricted).

## CSRF Protection

Mutating endpoints called from the browser use `validateOrigin(request)` which checks the `Origin` header against the app URL. Hook/webhook endpoints skip this.

## Error Format

All errors return:

```json
{ "error": "Human-readable message" }
```

Status codes: `400` (validation), `401` (unauthorized), `404` (not found), `429` (rate limited), `500` (server error), `502` (upstream failure), `503` (unavailable).

## Tasks

### `GET /api/tasks`

List tasks.

| Query Param      | Type              | Default  | Description                                             |
| ---------------- | ----------------- | -------- | ------------------------------------------------------- |
| `status`         | string            | --       | Filter by status (`inbox`, `in_progress`, `done`, etc.) |
| `project_id`     | string            | --       | Filter by project                                       |
| `top_level_only` | `"true"\|"false"` | `"true"` | Exclude child tasks                                     |

**Response:** `Task[]`

### `POST /api/tasks`

Create a task. CSRF-protected.

**Body:**

```json
{
  "title": "string (required, max 500)",
  "description": "string",
  "priority": "urgent | high | normal | low",
  "assignee": "string",
  "parent_id": "uuid (single-level nesting only)",
  "project_id": "uuid",
  "depends_on": ["uuid"],
  "spawned_by": "string (agent name or uuid)"
}
```

**Response:** `201` with created `Task`.

### `GET /api/tasks/:id`

Get a single task by ID.

**Response:** `Task`

### `PUT /api/tasks/:id`

Update a task. CSRF-protected. Allowed fields: `title`, `description`, `outcome`, `status`, `priority`, `assignee`, `due_date`, `depends_on`, `metadata`, `sort_order`, `parent_id`, `project_id`, `category`, `completed_at`, `effort`.

Validates `depends_on` for self-references and depth-1 circular dependencies. When moving to `done`, auto-stamps `completed_at` and clears `active_session` metadata.

**Response:** Updated `Task`.

### `DELETE /api/tasks/:id`

Delete a task. CSRF-protected.

**Response:** `204` No Content.

### `GET /api/tasks/:id/children`

Get child tasks and completion status.

**Response:**

```json
{
  "children": "Task[]",
  "all_complete": "boolean"
}
```

### `GET /api/tasks/:id/context`

Get memory context entries linked to a task via `context_keys`.

**Response:**

```json
{
  "context_keys": ["string"],
  "entries": "MemoryEntry[]"
}
```

### `GET /api/tasks/:id/comments`

List comments on a task.

**Response:** `Comment[]`

### `POST /api/tasks/:id/comments`

Add a comment.

**Body:**

```json
{
  "author": "string (required)",
  "content": "string (required)"
}
```

**Response:** `201` with created `Comment`.

### `GET /api/tasks/:id/dependencies`

Get full task objects for all items in the task's `depends_on` array.

**Response:**

```json
{ "dependencies": "Task[]" }
```

### `GET /api/tasks/:id/spawned`

Get tasks spawned by a given task (where `spawned_by` equals the task ID).

**Response:**

```json
{ "tasks": "Task[]" }
```

### `POST /api/tasks/:id/initiate`

Initiate a task: sets status to `in_progress`, stamps metadata (`initiated`, `active_session`, `claimed_by`), and upserts `agent_status` to `working`.

**Response:** Updated `Task`.

### `GET /api/tasks/:id/usage`

Aggregate Claude API token usage for a specific task from `claude_usage` table.

**Response:**

```json
{
  "hasUsage": true,
  "requests": 5,
  "models": ["claude-sonnet-4-6"],
  "inputTokens": 1000,
  "outputTokens": 500,
  "cacheReadTokens": 200,
  "cacheCreationTokens": 100,
  "totalCost": 0.05,
  "totalDurationMs": 3000,
  "totalTokens": 1500
}
```

Returns `{ "hasUsage": false }` if no usage data exists.

### `POST /api/tasks/generate`

AI-powered task generation using Claude. CSRF-protected.

**Body:**

```json
{
  "prompt": "string (required)",
  "project_id": "uuid (optional)"
}
```

**Response:** `201` with created `Task` (title, description, priority, assignee generated by AI).

### `PUT /api/tasks/reorder`

Batch reorder tasks with status changes. CSRF-protected. Detects status transitions and logs activity. Handles `done` transitions (clears sessions, updates agent status).

**Body:**

```json
[{ "id": "uuid", "status": "string", "sort_order": 0 }]
```

**Response:** `{ "ok": true }`

### `GET /api/tasks/stream` (deprecated)

SSE stream of Supabase Realtime task changes. Superseded by direct Supabase Realtime subscriptions in the browser. Returns `text/event-stream`.

## Activity

### `GET /api/activity`

List activity log entries with filtering.

| Query Param    | Type              | Description                     |
| -------------- | ----------------- | ------------------------------- |
| `event_type`   | string            | Filter by event type            |
| `severity`     | string            | Single severity filter          |
| `severity_in`  | string            | Comma-separated severity list   |
| `agent_id`     | string            | Filter by agent                 |
| `task_id`      | string            | Filter by task                  |
| `acknowledged` | `"true"\|"false"` | Filter by acknowledgment status |
| `limit`        | number            | Pagination limit                |
| `offset`       | number            | Pagination offset               |

**Response:** Activity entries (shape depends on `getActivity` query).

### `POST /api/activity`

Create an activity log entry.

**Body:**

```json
{
  "event_type": "string (required)",
  "severity": "info | warning | error (required)",
  "source": "string (required)",
  "title": "string (required)",
  "details": "object (optional)",
  "task_id": "uuid (optional)"
}
```

**Response:** `201` with created activity entry.

### `PATCH /api/activity`

Acknowledge activity entries.

**Body:**

```json
{ "ids": ["uuid"] }
```

**Response:**

```json
{ "acknowledged": 3 }
```

## Agents

### `GET /api/agents/status`

Get all agent statuses. Returns a map keyed by lowercase agent name. Auto-cleans stale `working` agents (heartbeat > 1 hour).

**Response:**

```json
{
  "rick": {
    "status": "online | working | offline",
    "last_heartbeat": "ISO string | null",
    "current_task_id": "uuid | null",
    "model": "string | null"
  }
}
```

### `GET /api/agents/health`

Agent roster health check. Compares code-defined agents against `agent_status` and `agent_configs` tables. Reports drift.

**Response:**

```json
{
  "healthy": true,
  "codeAgents": ["rick", "sage", "noir"],
  "drift": {
    "inCodeNotStatus": [],
    "inStatusNotCode": [],
    "inCodeNotConfig": [],
    "inConfigNotCode": []
  }
}
```

### `GET /api/agents/delegations`

Returns delegation flow data -- edges between agents where tasks were handed off via `metadata.delegated_by`.

**Response:**

```json
{
  "edges": [
    {
      "from": "rick",
      "to": "sage",
      "count": 3,
      "tasks": [{ "id": "uuid", "title": "string", "delegated_at": "ISO string" }]
    }
  ],
  "stats": {
    "rick": { "delegated_out": 3, "received": 1 }
  }
}
```

### `GET /api/agents/:id/audit`

Get audit trail for a specific agent.

| Query Param | Type   | Description       |
| ----------- | ------ | ----------------- |
| `limit`     | number | Pagination limit  |
| `offset`    | number | Pagination offset |

**Response:** Audit trail entries for the agent.

### `GET /api/agents/:id/config`

Get agent configuration (personality parameters and active profile). Falls back to static defaults from `agents-data.ts` if no DB row exists.

**Response:**

```json
{
  "parameters": { "humor": 75, "honesty": 80, "...": "..." },
  "active_profile": "default"
}
```

### `PUT /api/agents/:id/config`

Update agent configuration.

**Body:**

```json
{
  "parameters": { "humor": 75, "honesty": 80, "...": "..." },
  "active_profile": "string"
}
```

**Response:** Updated config.

### `GET /api/agents/:id/permissions`

Get effective permission scopes for an agent. Returns static defaults or DB override.

**Response:**

```json
{
  "agentId": "sage",
  "permissions": ["call_claude", "read_tasks", "..."],
  "source": "static | override"
}
```

### `PUT /api/agents/:id/permissions`

Override agent permissions. Pass `null` to revert to static defaults.

**Body:**

```json
{ "permissions": ["scope1", "scope2"] }
```

or

```json
{ "permissions": null }
```

**Response:** Same shape as GET with updated `source`.

### `POST /api/agents/:id/chat`

Stream a chat response from an agent. Requires `call_claude` permission. Uses personality parameters to build a dynamic system prompt.

**Body:**

```json
{
  "messages": [{ "role": "user", "content": "string" }],
  "parameters": { "humor": 75, "honesty": 80, "...": "..." },
  "voice_mode": false
}
```

**Response:** `text/plain` streaming response (chunked text deltas). When `voice_mode` is true, responses are shorter and formatted for TTS.

## Voice / TTS

### `GET /api/agents/:id/voice`

Get available ElevenLabs voices and the agent's current voice settings.

**Response:**

```json
{
  "voices": "ElevenLabsVoice[]",
  "current": "VoiceSettings | null"
}
```

### `PUT /api/agents/:id/voice`

Set an agent's voice configuration.

**Body:**

```json
{
  "provider": "elevenlabs",
  "voice_id": "string (required)",
  "voice_name": "string (required)",
  "params": {
    "stability": 0.5,
    "similarity_boost": 0.75,
    "style": 0,
    "speed": 1.0,
    "model_id": "string",
    "output_format": "string"
  },
  "system_prompt": "string (optional)"
}
```

**Response:** Updated `voice_settings`.

### `POST /api/agents/:id/voice/clone`

Clone a voice from audio samples via ElevenLabs.

**Body:** `multipart/form-data` with fields:

- `name` (string, required)
- `description` (string, optional)
- `files` (audio files, at least one required)

**Response:**

```json
{
  "voice_id": "string",
  "name": "string"
}
```

### `GET /api/agents/:id/voice/dictionary`

Get the pronunciation dictionary locator for an agent.

**Response:**

```json
{
  "pronunciation_dictionary_id": "string | null",
  "pronunciation_dictionary_version_id": "string | null"
}
```

### `POST /api/agents/:id/voice/dictionary`

Create/update the pronunciation dictionary for an agent via ElevenLabs. Requires voice settings to be configured first.

**Response:**

```json
{
  "pronunciation_dictionary_id": "string",
  "pronunciation_dictionary_version_id": "string"
}
```

### `POST /api/agents/:id/voice/tts`

Generate speech with word-level timestamps (JSON response).

**Body:**

```json
{
  "voice_id": "string (required)",
  "text": "string",
  "params": { "stability": 0.5, "similarity_boost": 0.75, "style": 0 },
  "previous_text": "string (optional, for context)"
}
```

**Response:**

```json
{
  "audio_base64": "string",
  "words": [{ "word": "Hello", "start": 0.0, "end": 0.3 }]
}
```

### `POST /api/agents/:id/voice/tts-stream`

Stream TTS audio chunks with word timestamps as Server-Sent Events.

**Body:** Same as `/voice/tts`.

**Response:** `text/event-stream` with events:

```
data: { "audio_base64": "...", "words": [...], "isFinal": false }
data: { "audio_base64": "...", "words": [...], "isFinal": true }
data: [DONE]
```

### `POST /api/agents/:id/voice/preview`

Generate a voice preview. Returns raw audio.

**Body:**

```json
{
  "voice_id": "string (required)",
  "text": "string",
  "params": { "stability": 0.5, "similarity_boost": 0.75, "style": 0, "model_id": "string" }
}
```

**Response:** `audio/mpeg` binary with `Cache-Control: public, max-age=3600`.

## Health

### `GET /api/health`

Run the Python health check script (checks heartbeat, slackbot, feed scanner, memory DB, API credits).

**Response:** Health check JSON from the script, or `503` if scripts are unavailable.

### `POST /api/health/check-and-alert`

Run the health check and create/update activity alerts for any failing services.

**Response:**

```json
{
  "checked": true,
  "alerts": [
    { "event_type": "integration.slack.offline", "action": "created", "instance_count": 1 }
  ]
}
```

### `GET /api/health/mcps`

List configured MCP servers from Claude Code config files (`~/.claude.json`).

**Response:**

```json
{
  "total": 5,
  "servers": [{ "name": "filesystem", "command": "npx", "scope": "global | project" }]
}
```

## Webhooks & Integrations

### `POST /api/hooks/notify`

Webhook receiver for Claude Code hook events. Authenticated via `X-Hook-Secret` header.

**Body:**

```json
{
  "event": "string (required)",
  "title": "string (required)",
  "severity": "info | warning | error",
  "source": "string",
  "details": "object",
  "task_id": "uuid",
  "agent_id": "string"
}
```

**Response:** `201` with `{ "ok": true, "id": "uuid" }`.

### `GET /api/alerts/sentry`

Fetch unresolved Sentry issues for the project. Requires `SENTRY_AUTH_TOKEN`.

**Response:**

```json
{
  "issues": [{
    "id": "sentry-123",
    "title": "TypeError: ...",
    "severity": "error",
    "event_type": "TypeError",
    "source": "sentry",
    "count": 15,
    "permalink": "https://sentry.io/...",
    "..."
  }]
}
```

Returns `{ "issues": [], "error": "..." }` on failure (always status `200`).

### `POST /api/slack/commands`

Slack slash command handler (`/remote`). Authenticated via Slack HMAC-SHA256 signature. Rate limited (10 commands/minute per user). User allowlist via `SLACK_ALLOWED_USER_IDS`.

Subcommands: `status`, `health`, `afk-toggle`, `deploy`, `help`.

**Body:** URL-encoded Slack command payload.

**Response:** Slack Block Kit message (ephemeral).

### `POST /api/auth/signout`

**Response:** `{ "success": true }`

## Portfolio

### `POST /api/portfolio/hash`

Generate a bcrypt password hash. CSRF-protected.

**Body:**

```json
{ "password": "string (required)" }
```

**Response:** `{ "password_hash": "string" }`

### `GET /api/portfolio/passwords`

List all portfolio password entries (without hashes).

**Response:**

```json
[
  {
    "id": "uuid",
    "project_id": "string",
    "project_title": "string",
    "title": "string | null",
    "created_at": "ISO",
    "updated_at": "ISO"
  }
]
```

### `POST /api/portfolio/passwords`

Create a portfolio password entry. CSRF-protected.

**Body:**

```json
{
  "project_id": "string (required)",
  "project_title": "string (required)",
  "password": "string (required)",
  "title": "string (optional)"
}
```

**Response:** `201` with created entry (without hash).

### `PATCH /api/portfolio/passwords/:id`

Update a portfolio password entry (password and/or title). CSRF-protected.

**Body:**

```json
{
  "password": "string (optional, to change)",
  "title": "string (optional)"
}
```

**Response:** Updated entry.

### `DELETE /api/portfolio/passwords/:id`

Delete a portfolio password entry. CSRF-protected.

**Response:** `204` No Content.

### `POST /api/portfolio/verify`

Public endpoint. Verify a password for a portfolio project. CORS-restricted. Rate limited (10 failed attempts per IP per hour, then blocked).

**Body:**

```json
{
  "password": "string (required)",
  "projectId": "string (required)"
}
```

**Response:**

```json
{ "success": true }
```

or

```json
{ "success": false, "warning": "You have 3 attempts remaining...", "attemptsRemaining": 3 }
```

Returns `429` when blocked.
